# 防登录卡死贝果小助手

解决一条龙「登录后卡死在空洞局内」的问题。

## 这个插件会改动主程序（重要）

**插件会在运行时接管主程序的登录流程节点**，具体是 `EnterGame` 的三个方法：
`check_enter_click_status`、`check_screen`、`wait_loading`。

- 只改内存里的方法指向，**不修改、不新增、不删除任何主程序文件**；
- 一条龙更新后不会覆盖，也不需要重新打补丁；
- 禁用或删除插件，主程序立即回到原生行为，没有残留；
- 日志里搜「防登录卡死补丁已生效」可以确认插件是否在工作。

如果你不接受插件修改主程序行为，请不要安装。

## 解决什么问题

在贝果计划、零号空洞这类玩法局内直接关掉游戏，再登录时游戏会把角色放回局内。
一条龙执行第一个应用前会先跑「检测游戏窗口 → 打开并进入游戏」，这一步用的
`EnterGame` 只认大世界画面和已知弹窗。角色留在玩法局内时两者都不是，它就会
一直重试到超时（默认 180 秒），后面的应用都会加载失败直到认识贝果的人出现。

这个插件在登录阶段识别出「角色还在玩法局内」，先把角色退出玩法回到大世界，
再让一条龙继续加载应用。

## 怎么识别

两条判据同时命中才算在局内：

1. 右上角有金黄色圆环计时图标（HSV 金黄 + 连通域外形）；
2. 右下角普攻按钮足够亮。

单条都会误判：计时图标在结算、回放里也可能出现；普攻按钮被面板遮住时会变暗。
区域坐标按 1920x1080 维护，2K 由框架自动换算。

## 退出流程

Esc 打开暂停菜单 → 点退出战斗 → 只确认玩法专用提示（「仅保留安全箱内物资」）
→ 结算点继续 → 结算仓库点「ESC 返回研究站」→ 再走通用返回大世界，
把角色从研究站带回大世界。

必须走到大世界为止：点返回研究站只是离开仓库，角色还停研究站，而一条龙本体
识别只认大世界，停在那里等于没退出。

结算仓库用「放入仓库 + 返回研究站」两个按钮同时可见来确认，点完必须确认界面
真的消失，否则按 Esc 兜底，仍不消失就明确失败，不会原地空转。

整条链总时长上限 120 秒，Esc 最多 3 次，同一处点击最多补点 2 次，
任何一步走不通都会明确失败返回。

## 会丢东西吗

会丢安全箱外的物资。这是游戏对「主动退出玩法」的既定规则，和你在游戏里自己
点退出战斗一致。插件不做入仓、出售、重开，那些属于各玩法自己的业务。

## 安装

插件管理页订阅安装，或把插件目录放进一条龙的 `plugins/` 下重启程序。
应用列表里会多一个「防登录卡死贝果小助手」条目，它本身不做任何事——
补丁在插件加载时就已经生效，勾不勾选都不影响。

装好后日志里应该能看到 `防登录卡死补丁已生效：check_enter_click_status, check_screen, wait_loading`。

## 已知限制

- 点击动作依赖真实游戏窗口，无法在无游戏环境下完整验证。
- 只处理「登录后落在空洞类玩法局内」这一种卡死。其它卡死原因不在范围内。
